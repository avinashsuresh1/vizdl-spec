# VizDL Specification (Version 1.0)

VizDL (Visual Design Language) is a declarative, mathematically rigorous modeling language for representing geometric forms, physical condensed-matter materials, and kinematic animations.

This repository serves as the authoritative Version 1.0 specification of the VizDL data model and its mathematical interfaces.

---

## The VizDL Model

VizDL models 3D scenes through five formal abstractions:

1. **Geometry via Intrinsic Curvature**: Curves are defined coordinate-free by their intrinsic curvature polynomial $\kappa(s) = \sum a_k s^k$. Surfaces are formed as parametric manifolds generated by sweeping or revolving cross-section profiles.
2. **Transformations via Geometric Algebra**: Spatial rotations and displacements are formulated in 3D Clifford Geometric Algebra $Cl(3,0)$ using planar rotors and motors ($M = T R$), eliminating coordinate bias and gimbal lock.
3. **Materials via the Condensed-Matter Triad**: Materials are defined by a normalized physical triad $(E_g, \rho_e, \sigma) \in [0.0, 1.0]^3$ representing bandgap energy, electron density, and microfacet roughness, strictly satisfying optical energy conservation $R_{\text{total}} + T + A = 1.0$.
4. **Radiance via Material Excitation**: Illumination is modeled as excited matter ($\epsilon \in [0.0, 1.0]$). Physical luminaires are geometric objects composed of excited materials, eliminating artificial light primitives.
5. **Kinematics via Four Pillars**: Time evolution is categorized into trajectory sweep, axis revolution, topological mesh morphing, and quantum excitation modulation.
6. **Universal Composition**: All entities (`profiles`, `materials`, `meshes`, `objects`, `animations`, `scenes`) require a unique identifier (`name = "<string>"`), ensuring deterministic referential composition.

## Project Structure

A VizDL project is organized into directory hierarchies corresponding to each entity category:

```
project/
├── profiles/     # 1D/2D cross-sections, 3D trajectories, and timing curves
├── materials/    # Normalized condensed-matter physical materials
├── meshes/       # 3D parametric sweep and revolve surfaces
├── objects/      # Hierarchical assemblies of mesh components
├── animations/   # Kinematic motion, morphing, and excitation modulation
└── scenes/       # Scene timeline, camera placement, and placed objects
```

## Minimal Specification Example

### 1. `profiles/circle.toml`
```toml
name = "circle"
start_point = [1.0, 0.0, 0.0]
curvature = 1.0
```

### 2. `materials/luminescent_crystal.toml`
```toml
name = "luminescent_crystal"
energy_gap = 0.95
electron_density = 0.35
roughness = 0.05
excitation = 0.80
```

### 3. `meshes/sphere.toml`
```toml
name = "sphere"
surface = "circle"
material = "luminescent_crystal"

[path]
mode = "revolve"
axis = "z"
angle = 360.0
```

### 4. `objects/beacon.toml`
```toml
name = "beacon"

[[components]]
name = "core"
mesh = "sphere"
scale = 1.5
```

### 5. `animations/orbital_spin.toml`
```toml
name = "orbital_spin"
duration = 8.0
loop = true

[motion]
mode = "revolve"
axis = "y"
angle = 360.0
offset = 4.0
```

### 6. `scenes/main.toml`
```toml
name = "main"
duration = 8.0
fps = 60.0
loop = true

[camera]
position = [0.0, 5.0, 10.0]
target = [0.0, 0.0, 0.0]
fov = 45.0

[[objects]]
name = "beacon_instance"
object = "beacon"
animation = "orbital_spin"
```
