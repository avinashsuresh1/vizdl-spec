# VizDL TOML Schema Specification

Complete, exhaustive declarative TOML schema for VizDL (Visual Design Language).

---

## 1. Profiles (`profiles/*.toml`)

Defines 2D cross-sections, 3D trajectory paths, or 1D/2D timing curves via intrinsic curvature polynomials:
$$\kappa(s) = \sum_{k=0}^n a_k s^k$$

### 1.1 Single-Curve Schema
```toml
name = "<string>"                 # Required. Unique profile identifier.
description = "<string>"          # Optional.
start_point = [<f64>, <f64>, <f64>] # Required. 3D start coordinate [x, y, z].
end_point = [<f64>, <f64>, <f64>]   # Optional. 3D end coordinate [x, y, z]. If omitted, curve is closed.

# Curvature specification. One of the following three formats:
# Format A: Constant curvature scalar (0.0 = straight line, c != 0 = circle of radius 1/|c|)
curvature = <f64>

# Format B: Polynomial coefficient array [a0, a1, a2, ...] where kappa(s) = a0 + a1*s + a2*s^2 + ...
# curvature = [<f64>, <f64>, ...]

# Format C: Explicit power-coefficient terms
# curvature = [
#   { power = <u32>, coeff = <f64> },
#   ...
# ]
```

### 1.2 Multi-Curve Composite Schema
```toml
name = "<string>"                 # Required. Unique profile identifier.
description = "<string>"          # Optional.

[[curves]]
name = "<string>"                 # Optional. Curve segment identifier.
start_point = [<f64>, <f64>, <f64>] # Required. Segment start coordinate [x, y, z].
end_point = [<f64>, <f64>, <f64>]   # Optional. Segment end coordinate [x, y, z].
curvature = <f64> | [<f64>, ...] | [{ power = <u32>, coeff = <f64> }, ...] # Required.

[[curves]]
name = "<string>"                 # Optional.
start_point = [<f64>, <f64>, <f64>] # Required.
end_point = [<f64>, <f64>, <f64>]   # Optional.
curvature = <f64> | [<f64>, ...] | [{ power = <u32>, coeff = <f64> }, ...] # Required.
```

## 2. Materials (`materials/*.toml`)

Defines optical and condensed-matter physical properties. All parameters normalized to `[0.0, 1.0]`.
Light emission is defined by electronic excitation ($\epsilon > 0.0$).

```toml
name = "<string>"                 # Required. Unique material identifier.
description = "<string>"          # Optional.
energy_gap = <f64>                # Required. Range: [0.0, 1.0]. Normalized bandgap energy.
electron_density = <f64>          # Required. Range: [0.0, 1.0]. Normalized electron density.
roughness = <f64>                 # Required. Range: [0.0, 1.0]. Normalized microfacet roughness.
excitation = <f64>                # Optional. Default: 0.0. Range: [0.0, 1.0]. Normalized electronic excitation level (glow emission).
```

## 3. Meshes (`meshes/*.toml`)

Defines 3D parametric surfaces generated by sweeping a profile along a trajectory curve or revolving a profile around an axis.

### 3.1 Sweep Mode Schema
```toml
name = "<string>"                 # Required. Unique mesh identifier.
description = "<string>"          # Optional.
surface = "<string>"              # Required. Identifier referencing cross-section profile in profiles/*.toml.
material = "<string>"             # Optional. Identifier referencing material in materials/*.toml. If omitted, inherits from parent object component.

[path]
mode = "sweep"                    # Required.
curve = "<string>"                # Required. Identifier referencing 3D trajectory curve profile in profiles/*.toml.

scale_profile = <f64> | [<f64>, ...] | [{ power = <u32>, coeff = <f64> }, ...] | "<string>"
                                  # Optional. Polynomial scaling or identifier referencing profile in profiles/*.toml.

caps = "none" | "start" | "end" | "both" # Optional. Default: "both". End-cap closure mode.
```

### 3.2 Revolve Mode Schema
```toml
name = "<string>"                 # Required. Unique mesh identifier.
description = "<string>"          # Optional.
surface = "<string>"              # Required. Identifier referencing cross-section profile in profiles/*.toml.
material = "<string>"             # Optional. Identifier referencing material in materials/*.toml. If omitted, inherits from parent object component.

[path]
mode = "revolve"                  # Required.
axis = "x" | "y" | "z" | [<f64>, <f64>, <f64>]
                                  # Optional. Default: "z". Revolution axis direction vector.
angle = <f64>                     # Optional. Default: 360.0. Revolution angle in degrees.
tilt_angle = <f64>                # Optional. Default: 90.0. Profile tilt angle relative to axis in degrees.
offset = <f64>                    # Optional. Default: 0.0. Radial offset distance from revolution axis.

scale_profile = <f64> | [<f64>, ...] | [{ power = <u32>, coeff = <f64> }, ...] | "<string>"
                                  # Optional. Polynomial scaling or identifier referencing profile in profiles/*.toml.

caps = "none" | "start" | "end" | "both" # Optional. Default: "none" for 360.0 deg, "both" otherwise.
```

## 4. Objects (`objects/*.toml`)

Defines hierarchical 3D assemblies composed of positioned and oriented mesh components.

```toml
name = "<string>"                 # Required. Unique assembly identifier.
description = "<string>"          # Optional.
material = "<string>"             # Optional. Fallback material identifier referencing materials/*.toml for components omitting material.

[[components]]
name = "<string>"                 # Required. Unique component identifier within the assembly.
mesh = "<string>"                 # Required. Identifier referencing mesh in meshes/*.toml.
material = "<string>"             # Optional. Material override identifier referencing materials/*.toml.
position = [<f64>, <f64>, <f64>]  # Optional. Default: [0.0, 0.0, 0.0]. 3D offset [x, y, z].
rotation = [<f64>, <f64>, <f64>]  # Optional. Default: [0.0, 0.0, 0.0]. Planar rotations [xy, yz, xz] in degrees.
scale = <f64> | [<f64>, <f64>, <f64>] # Optional. Default: 1.0. Uniform scale factor <f64> or per-axis scale factors [sx, sy, sz].

[[components]]
name = "<string>"                 # Required.
mesh = "<string>"                 # Required.
material = "<string>"             # Optional.
position = [<f64>, <f64>, <f64>]  # Optional. Default: [0.0, 0.0, 0.0].
rotation = [<f64>, <f64>, <f64>]  # Optional. Default: [0.0, 0.0, 0.0].
scale = <f64> | [<f64>, <f64>, <f64>] # Optional. Default: 1.0.
```

## 5. Animations (`animations/*.toml`)

Defines the 4 pillars of animation: trajectory sweep, axis revolution, shape morphing, and excitation glow modulation.

```toml
name = "<string>"                 # Required. Unique animation identifier.
description = "<string>"          # Optional.
duration = <f64>                  # Required. Cycle duration in seconds. Range: > 0.0.
loop = <bool>                     # Optional. Default: false. Repeat animation cycle.
loop_start = <f64>                # Optional. Default: 0.0. Start timestamp of loop region in seconds.
loop_end = <f64>                  # Optional. Default: duration. End timestamp of loop region in seconds.

# --- Pillar 1: Curve Sweep OR Pillar 2: Axis Revolution ---
[motion]                          # Optional.
mode = "sweep" | "revolve"        # Optional. Default: "sweep".

# When mode = "sweep":
path = "<string>"                 # Required (for sweep mode). Identifier referencing trajectory profile in profiles/*.toml.
timing = "<string>"               # Optional. Default: "linear". Pacing curve in profiles/*.toml or easing ("linear" | "ease_in" | "ease_out" | "ease_in_out").

# When mode = "revolve":
axis = "x" | "y" | "z" | [<f64>, <f64>, <f64>] # Optional. Default: "z". Revolution axis direction vector.
angle = <f64>                     # Optional. Default: 360.0. Total revolution angle in degrees.
offset = <f64>                    # Optional. Default: 0.0. Orbital radius from revolution axis.
timing = "<string>"               # Optional. Default: "linear". Pacing curve in profiles/*.toml or easing.

# --- Pillar 3: Shape Morphing ---
[morph]                           # Optional.
target_object = "<string>"        # Required (if morph block present). Identifier referencing target object in objects/*.toml.
timing = "<string>"               # Optional. Default: "linear". Pacing curve in profiles/*.toml or easing.

# --- Pillar 4: Excitation Glow Modulation ---
[excitation]                      # Optional.
start = <f64>                     # Required (if excitation block present). Excitation at start (u = 0.0). Range: [0.0, 1.0].
end = <f64>                       # Required (if excitation block present). Excitation at end (u = 1.0). Range: [0.0, 1.0].
timing = "<string>"               # Optional. Default: "linear". Pacing curve in profiles/*.toml or easing.

# --- Director Camera Track ---
[camera]                          # Optional.
mode = "sweep" | "revolve"        # Optional. Default: "sweep".

# When mode = "sweep":
path = "<string>"                 # Optional. Camera position trajectory profile identifier in profiles/*.toml.
target_path = "<string>"          # Optional. Camera look-at trajectory profile identifier in profiles/*.toml.
target = [<f64>, <f64>, <f64>]    # Optional. Static look-at target position [x, y, z].

# When mode = "revolve":
axis = "x" | "y" | "z" | [<f64>, <f64>, <f64>] # Optional. Default: "z". Orbit axis direction vector.
target = [<f64>, <f64>, <f64>]    # Optional. Orbit center / look-at target [x, y, z].
angle = <f64>                     # Optional. Default: 360.0. Total orbit angle in degrees.
offset = <f64>                    # Optional. Default: 0.0. Orbit radius from target.

fov_start = <f64>                 # Optional. Initial field of view in degrees. Range: (0.0, 180.0).
fov_end = <f64>                   # Optional. Final field of view in degrees. Range: (0.0, 180.0).
timing = "<string>"               # Optional. Default: "linear". Pacing curve in profiles/*.toml or easing.
```

## 6. Scenes (`scenes/*.toml`)

Defines master timeline, camera placement, and placed object instances.
Light is emitted physically by objects whose materials have excitation > 0.0 (no external light primitives).

```toml
name = "<string>"                 # Required. Unique scene identifier.
description = "<string>"          # Optional.
duration = <f64>                  # Required. Scene duration in seconds. Range: > 0.0.
fps = <f64>                       # Optional. Default: 60.0. Frame evaluation rate.
loop = <bool>                     # Optional. Default: false. Repeat scene timeline.
loop_start = <f64>                # Optional. Default: 0.0. Start timestamp of scene loop region in seconds.
loop_end = <f64>                  # Optional. Default: duration. End timestamp of scene loop region in seconds.

[camera]                          # Optional. Scene camera.
position = [<f64>, <f64>, <f64>]  # Optional. Default: [0.0, 0.0, 5.0]. Camera position [x, y, z].
target = "<string>" | [<f64>, <f64>, <f64>] # Optional. Tracked object instance identifier or static [x, y, z] target.
fov = <f64>                       # Optional. Default: 50.0. Field of view in degrees. Range: (0.0, 180.0).
animation = "<string>"            # Optional. Identifier referencing camera track animation in animations/*.toml.

[[objects]]                       # Required (at least one). Placed object instances.
name = "<string>"                 # Required. Unique instance identifier within the scene.
object = "<string>"               # Required. Identifier referencing object in objects/*.toml.
position = [<f64>, <f64>, <f64>]  # Optional. Default: [0.0, 0.0, 0.0]. Placement offset [x, y, z].
rotation = [<f64>, <f64>, <f64>]  # Optional. Default: [0.0, 0.0, 0.0]. Planar rotations [xy, yz, xz] in degrees.
scale = <f64> | [<f64>, <f64>, <f64>] # Optional. Default: 1.0. Uniform scale factor <f64> or per-axis scale factors [sx, sy, sz].
animation = "<string>"            # Optional. Identifier referencing animation in animations/*.toml.
start_time = <f64>                # Optional. Default: 0.0. Start timestamp on scene timeline in seconds.
```
