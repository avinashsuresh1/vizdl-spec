# Meshes in VizDL

Meshes define 3D parametric surfaces formed by sweeping a cross-section profile along a trajectory curve or revolving it around a directional axis.

---

## 1. Dual Generation Modes

VizDL eliminates arbitrary polygonal triangle soup in favor of clean, continuous parametric surfaces generated by two dual operations:

1. **Sweep**: Extrudes a cross-section profile along a 3D trajectory curve.
2. **Revolve**: Rotates a cross-section profile around a 3D directional axis.

Both modes support longitudinal polynomial scaling (`scale_profile`) and end-cap closure control (`caps`).

---

## 2. Sweep Mode

Sweeps a cross-section profile along an intrinsic 3D trajectory curve.

```toml
name = "<string>"                 # Required. Unique mesh identifier.
description = "<string>"          # Optional.
surface = "<string>"              # Required. Cross-section profile in profiles/*.toml.
material = "<string>"             # Optional. Base material in materials/*.toml.

[path]
mode = "sweep"                    # Required.
curve = "<string>"                # Required. 3D trajectory curve profile in profiles/*.toml.

scale_profile = <f64> | [<f64>, ...] | [{ power = <u32>, coeff = <f64> }, ...] | "<string>"
                                  # Optional. Longitudinal scaling polynomial or profile identifier.

caps = "none" | "start" | "end" | "both" # Optional. Default: "both". End-cap closure mode.
```

### Example: Cylindrical Pipe
Sweeps a circular cross-section along a straight line trajectory:

```toml
name = "pipe"
surface = "unit_circle"
material = "polished_metal"

[path]
mode = "sweep"
curve = "straight_line"
caps = "both"
```

### Example: Tapered Horn
Sweeps a circle along a straight path while tapering via a polynomial scale profile:

```toml
name = "tapered_horn"
surface = "unit_circle"

[path]
mode = "sweep"
curve = "straight_line"

# S(s) = 1.0 - 0.8 * s (tapers from 1.0 to 0.2)
scale_profile = [1.0, -0.8]
caps = "both"
```

---

## 3. Revolve Mode

Generates surfaces of revolution by rotating a cross-section profile around a directional axis.

```toml
name = "<string>"                 # Required. Unique mesh identifier.
description = "<string>"          # Optional.
surface = "<string>"              # Required. Profile in profiles/*.toml.
material = "<string>"             # Optional. Base material in materials/*.toml.

[path]
mode = "revolve"                  # Required.
axis = "x" | "y" | "z" | [<f64>, <f64>, <f64>]
                                  # Optional. Default: "z". Revolution axis direction vector.
angle = <f64>                     # Optional. Default: 360.0. Revolution angle in degrees.
tilt_angle = <f64>                # Optional. Default: 90.0. Profile tilt angle relative to axis.
offset = <f64>                    # Optional. Default: 0.0. Radial offset from axis.

scale_profile = <f64> | [<f64>, ...] | [{ power = <u32>, coeff = <f64> }, ...] | "<string>"
                                  # Optional. Longitudinal scaling polynomial.

caps = "none" | "start" | "end" | "both" # Optional. Default: "none" for 360 deg, "both" otherwise.
```

### Example: Sphere
Revolving a semicircular arc around the Z-axis:

```toml
name = "sphere"
surface = "semi_circle"
material = "clear_glass"

[path]
mode = "revolve"
axis = "z"
angle = 360.0
```

### Example: Torus
Revolving a closed circle around the Z-axis with a positive radial offset:

```toml
name = "torus"
surface = "unit_circle"

[path]
mode = "revolve"
axis = "z"
angle = 360.0
offset = 3.0 # Major radius of torus
```
